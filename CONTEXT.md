> Этот файл — сжатый слепок диалога заказчика и ассистента OpenHands от 18–19 октября 2026 г.
> При переходе в новый чат: приложите этот файл (или его содержимое) первым сообщением.

## 1. Цель проекта
Пользовательская ОС для ПК x86-64 с рабочим столом, визуально похожим на Windows 10,
но написанная полностью с нуля («чистая комната»), без кода Microsoft — чтобы не было
проблем с авторскими правами. UI-паттерны (панель задач, «Пуск», окна) не охраняются
копирайтом; охраняется код и торговые марки — их использовать запрещено.

Название ОС: **«ИрНа»** (вымышленное, правообладателей не имеет). Имя вынесено отдельно
в `branding.md` — перед релизом можно переименовать правкой 1–2 файлов.

## 2. Стек технологий (утверждено)
- **Ядро и системные сервисы:** Rust (безопасность памяти, отсутствие UB).
- **GUI / оконный сервер / приложения:** C++ + Qt6 (LGPL — легально при динамической линковке).
- **Window Server:** собственный, self-developed (решение D-010; +1–2 месяца к этапу M3).
- **Python — исключён из ядра и сервисов** (GIL, интерпретатор, производительность). Не используется.
- **EXE (Win32):** эмуляция отложена до работающего прототипа (D-007).
- **Шрифт по умолчанию:** PT Sans (кириллица, OFL, близок к Segoe UI) — D-011, ожидает финального «ок».
- **Лицензия проекта:** MIT (файл LICENSE создан) — D-009.
- **Русский язык:** кириллица в UI и пользовательских данных; технический слой (API, пути, протоколы) — ASCII/UTF-8. Полностью убрать латиницу из системного уровня невозможно и не нужно.

## 3. Архитектура (кратко,см. SPEC.md)
Загрузчик (GRUB/Liminx или свой stage) → Ядро Rust (планировщик, память, драйверы: VGA/QEMU, ATA, клавиатура, мышь) → Системные сервисы Rust (init, IPC) → Window Server C++/Qt → Desktop Shell (панель задач, «Пуск», проводник) → Приложения: Блокнот, Видеоплеер (приоритет MVP).

## 4. Этапы (ROADMAP.md)
- **M0** — тулчейн: WSL2 Ubuntu + Rust toolchain + Qt6 + QEMU/KVM. Сборка hello-kernel в QEMU.
- **M1** — ядро: загрузка, фреймбуфер, вывод текста, примитивные драйверы (клавиатура/мышь через PS/2 virtio).
- **M2** — память, планировщик, системные вызовы, загрузка ELF-пользовательских процессов.
- **M3** — window server + первый GUI-процесс в QEMU.
- **M4** — рабочий стол Windows-подобный: панель задач, «Пуск», окна (перетаскивание, ресайз), Блокнот.
- **M5** — видеоплеер, файловый менеджер, полировка. Регулярные прогоны на реальном железе после M3.
