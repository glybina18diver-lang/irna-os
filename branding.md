# BRANDING.md — единый источник имени и брендинга ОС «ИрНа»

**Правило:** имя ОС нигде в коде не хардкодится. Все места, где имя
появляется в UI, собираются из этого файла + заголовочного файла-константы.
Переименование перед релизом = правка 1–2 файлов + регенерация констант.

---

## 1. Реестр использования имени

| # | Место | Где физически | Как переименовать |
|---|-------|---------------|-------------------|
| B1 | Отображаемое имя в UI (панель «О системе», меню «Пуск», приветствие) | `branding/name.h` → `BRAND_NAME_DISPLAY` | правка 1 строки |
| B2 | Загрузочная строка («ИрНа booting...») | `bootloader/config.toml` → `display_name` | правка 1 строки |
| B3 | Имя ядра в логах/serial | `kernel/src/brand.rs` → `pub const KERNEL_NAME` | правка 1 строки |
| B4 | Каталог установки / корень ФС (`/Irina` или `/usr/irna`) | `images/build-disk.sh` → переменная `OS_ROOT` | скрипт пересборки образа |
| B5 | Имя пакета/репозитория на GitHub | настройки GitHub + git remote | смена имени репо |
| B6 | Логотип/иконка «Пуск» | `artwork/logo.svg` (своя отрисовка!) | замена SVG |
| B7 | Название window server-сокета | `winserv/src/main.cpp` → `BRAND_WS_SOCKET` (например `/dev/winserv`) | правка 1 строки |
| B8 | User-agent сетевых клиентов (Phase 2) | `libs/net/config` | правка 1 строки |

Формат идентификаторов (нижний регистр, ASCII): `irna`
Формат отображения (UTF-8, кириллица): `ИрНа`

## 2. Производные названия компонентов (нейтральные, без имени ОС)

Приложения названы общими словами, чтобы не требовать переименования:
- Блокнот → **«Блокнот»** (notepad)
- Плеер → **«Просмотр»** (player)
- Файлы → **«Файлы»** (filemanager)
- Настройки → **«Настройки»** (settings)

## 3. Что НЕ является именем и не меняется при ребрендинге
- ABI, имена системных вызовов, пути `/bin`, `/dev`, `/proc` — технический слой (ASCII).
- Внутренние имена функций/классов/модулей кода.
