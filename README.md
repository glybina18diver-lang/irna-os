# ИрНа (irna-os)

Настольная операционная система для x86-64 с интерфейсом в стиле Windows 10,
пишемая с нуля (принцип «чистой комнаты», лицензия MIT).

- **Ядро и сервисы:** Rust (no_std)
- **Оконный сервер:** собственный, C++
- **Оболочка и приложения (Блокнот, Плеер):** C++ / Qt 6

## Статус
M0 закрыт. Проект на этапе **M1** (базовое ядро): bootinfo, PMM, GDT+TSS, heap, VGA text.
См. [ROADMAP.md](ROADMAP.md) и [docs/STATE.md](docs/STATE.md).

## Правила разработки
1. Имя ОС не хардкодится — только через константы из `branding.md`.
2. Каждое архитектурное решение — запись в DECISIONS.md.
3. Коммиты с префиксом компонента: `kernel: ...`, `winserv: ...`, `docs: ...`.
4. Никакого кода Microsoft; сторонние зависимости — только MIT/Apache/BSD/LGPL(динамически).
